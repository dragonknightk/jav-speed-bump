这些图片只用于 Chrome Web Store 商品详情，不打进扩展安装包。`npm run build` 只打包 `manifest.json`、`_locales/` 与 `src/`，不会包含本目录。上传商店请使用 `dist/jav-speed-bump-store.zip`。
