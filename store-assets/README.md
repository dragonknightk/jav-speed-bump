# Chrome 网上应用店宣传图

这些图片只用于 Chrome Web Store 商品详情，不打进扩展安装包。`npm run build` 只打包 `manifest.json` 与 `src/`，不会包含本目录。上传商店用 `dist/jav-speed-bump-store.zip`。画面对应 0.4.0 的界面。

截图里出现的网站都是占位域名（例如 `example-blocked.com`、`example-videos.net`、`example-gallery.org`、`example-forum.io`），不是真实站点。
